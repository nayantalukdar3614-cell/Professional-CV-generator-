# CV Generator (A4)

1. Unzip the folder.
2. Open `index.html` in Chrome / Edge / Firefox (no internet needed).
3. Fill the forms. Data auto-saves in your browser.
4. Click "Save PDF / Print", choose Color or Black & White, then "Save PDF" (downloads an A4 PDF; needs internet once to load the PDF engine) or "Print" (print dialog: A4, Margins None, Background graphics on).

Buttons: Clear (backs up then clears), Restore (brings the cleared data back).
Works on mobile (Edit / Preview tabs) and desktop.
